# HomePageAPP Workspace Artifacts

This folder contains non-runtime files moved out of the app root to keep `HomePageAPP` tidy.

## What belongs here
- Debug captures and screenshots.
- Local Vite cache snapshots.
- One-off analysis scripts and their outputs.
- Temporary modules, JSON payloads, and served HTML snapshots.
- Preview/reference media not used by `index.html` at runtime.

## Runtime safety
- `index.html`, `src/`, `Images/`, `HomePageMusic/`, and active background media remain at the root.
- No runtime imports reference files in `_workspace/`.
- If needed, artifacts here can be regenerated by tooling workflows.
