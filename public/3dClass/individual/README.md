# Individual PNG Folder

This folder is your working area for clickable PNGs and their linked project folders.

How to use:
1. Open `index.html` and switch to **Manager**.
2. Click **Connect individual folder** and choose the `individual` directory.
3. Use:
   - **Upload PNG entries** to add one or many PNG files and create matching folders.
   - **Manage manifest entries** to edit labels, custom targets, and remove entries.
   - **Upload project files** per-row to place files into that project folder directly.
4. Use **Download manifest** for a local copy or **Save manifest to connected folder** to write `image-manifest.json`.

Folder convention:
- A PNG file `Laptop.png` maps to default target `./Laptop/index.html`.
- You can override target in the table. File links support folder or direct page paths.
