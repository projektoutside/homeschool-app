Single Player opens the progressive/custom choices described below; 2 Player VS Mode opens the existing configurable setup, defaulting to three birds and 60 seconds. Menu sound follows the existing shared mute state.

The single-player VS launcher, brand tagline and visible status/strategy paragraph no longer take layout space. Status announcements remain available to screen readers; VS editor instructions remain visible. ## Single Player choices follow-up — 2026-10-22

Scope/decisions: reuse the illustrated menu and existing level map. Progressive Play starts a fresh attempt at Level 1 and follows the existing sequential campaign. Custom Play selects a specific unlocked level; keeping earned locks is a delegated default based on the existing progression requirement. Neither entry resets earned stars, unlocked levels, coins or upgrades. Continue resumes a saved level or unfinished attempt without replacing its drawn route. Back/Escape returns to the two-mode main menu, and cancelling Custom Play returns focus to its launcher. No new images, storage formats, economy rules or game physics are required.

Implementation uses the existing menu shell and native level-map dialog. The choice buttons stack on phones and form two columns in short landscape. The level map retains its justified vertical contained scroll for 18 levels (`#mapScroll`, long-content/expanded-content); header and return controls stay reachable. The primary menu and choices do not scroll. No text fields or new keyboard permission surfaces are introduced.

Starting a new attempt while a menu is open now resets the menu pause reference to that attempt's start. Closing a level map over the menu does not separately add the same paused duration. This avoids double-counted pause time and negative clear times on a fresh progressive/custom attempt.
