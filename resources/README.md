# Native App Assets

The install experience uses the same branding across:

- `public/manifest.json`
- installed browser PWA icons
- Capacitor native app packaging

Current source artwork lives in:

- `public/icons/icon-source.svg`
- `public/icons/icon-512x512.png`

Use those assets when generating final Android/iOS store icons and splash assets so the native wrappers match the web install experience exactly.
